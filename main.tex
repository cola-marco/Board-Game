\subsection{Report Writing Contributions}
%\subsubsection*{Section-by-Section Breakdown}
\begin{itemize}
    \item \textbf{Section 1 - Game Rules:} Michele Berlato
        \begin{itemize}
            \item Detailed description of Kalaha rules and gameplay mechanics.
            \item Explanation of board representation and action semantics.
        \end{itemize}

    \item \textbf{Section 2 - Game Type:} Alexandros Kouros
        \begin{itemize}
            \item Formalization of the game type and structural properties.
            \item Analysis of its suitability for adversarial search methods.
        \end{itemize}
    \item \textbf{Section 3 - Size space:} Marco Cola
        \begin{itemize}
            \item Derivation of upper bounds for the state space using combinatorial analysis.
            \item Discussion of branching factor and computational complexity.
            \item Analysis of why exhaustive search is computationally infeasible.
        \end{itemize}
    \item \textbf{Section 4 - Elements of the game:} Marco Cola
        \begin{itemize}
            \item Formal definition of the game as a search problem.
            \item Specification of core components: initial state, player function, actions, result function, terminal test, and utility.
            \item Mapping of theoretical concepts to the implemented game model.
        \end{itemize}
    \item \textbf{Section 5 - AI states and moves representation:} Mattia Russo
        \begin{itemize}
            \item Representation of the game state as a fixed-size vector encoding the board configuration.
            \item Formalization of move representation as pit indices and their mapping to game actions.
            \item Description of deterministic state transitions and their role in search.
        \end{itemize}
    \item \textbf{Section 6 - Methods \& Algorithms:} Michele Berlato
        \begin{itemize}
            \item Explanation of Minimax and Alpha-Beta pruning algorithms.
            \item Description of recursive evaluation and pruning conditions.
            \item Construction of illustrative examples of algorithm execution.
        \end{itemize}
    \item \textbf{Section 7 - Heuristics and Evaluation functions:} Mattia Russo
        \begin{itemize}
            \item Evaluation function design and interpretation of heuristic terms.
        \end{itemize}
    \item \textbf{Section 8 - Implemented AI's parameters:} Marco Cola
        \begin{itemize}
            \item Definition of configurable AI parameters (depth and algorithm choice).
            \item Generation and presentation of benchmark figures.
            \item Analysis and interpretation of performance trends (time, win rate, node count).
        \end{itemize}
    \item \textbf{Section 9 - Future work:} Mattia Russo
        \begin{itemize}
            \item Identification of potential improvements and extensions.
        \end{itemize}
\end{itemize}
